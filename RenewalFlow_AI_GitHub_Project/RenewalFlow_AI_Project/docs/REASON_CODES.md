# Reason codes

| Code | Meaning | Suggested owner |
|---|---|---|
| PAYMENT_NOT_SETTLED | Payment is not confirmed as settled | Finance / Ops |
| MISSING_TEACHER_FORM | No teacher renewal form found for invoice | Teacher |
| MISSING_BOOKING_REQUEST | No booking request found for invoice | Operations |
| STUDENT_ID_MISMATCH | Invoice and form student IDs differ | Operations |
| AMOUNT_MISMATCH | Invoice and form amounts differ | Finance / Ops |
| STUDENT_NOT_UNIQUELY_MATCHED | Student ID missing or absent from active reference | Operations |
| BATCH_CHANGE_REQUIRED | Requested batch differs from current batch | Scheduling |
| BATCH_DATA_MISSING | Current or requested batch is missing | Scheduling |
| EXISTING_SCHEDULE_REVIEW | Student already has a schedule record | Operations |
| DUPLICATE_INVOICE_ID | Invoice ID occurs more than once | Operations |
